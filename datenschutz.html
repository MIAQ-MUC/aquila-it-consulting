4. Kontaktformular auf dieser Website

Das Formular auf dieser Website versendet keine Daten an einen Server dieser Website. Beim Anklicken der Schaltfläche wird lediglich Ihr lokal installiertes E-Mail-Programm mit einer vorbereiteten Nachricht geöffnet. Die eigentliche Datenübermittlung erfolgt erst dann, wenn Sie die E-Mail in Ihrem E-Mail-Programm selbst versenden. Bis zu diesem Zeitpunkt verbleiben Ihre Eingaben ausschließlich auf Ihrem Endgerät.

5. Cookies, Tracking und lokaler Speicher

Diese Website verwendet keine Analysewerkzeuge, kein Werbetracking, keine Social-Media-Plugins und keine nicht erforderlichen Cookies.

Wenn Sie über die Schaltfläche im Kopfbereich zwischen der hellen und der dunklen Ansicht wechseln, wird diese Auswahl im lokalen Speicher Ihres Browsers (localStorage) unter dem Schlüssel aic-theme abgelegt, damit die gewählte Ansicht bei einem erneuten Besuch erhalten bleibt. Es handelt sich dabei um eine rein technische Komforteinstellung. Es werden keine personenbezogenen Daten gespeichert, keine Daten an mich oder Dritte übertragen und keine Profile gebildet. Sie können diesen Eintrag jederzeit über die Einstellungen Ihres Browsers löschen.
